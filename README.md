## Enlace de descarga de MySQL Workbench Community:
https://dev.mysql.com/downloads/workbench/

El MSI Installer es el recomendado para Windows. Descargar e instalar.

Para MacOS, descargar el archivo DMG y arrastrar el icono de MySQL Workbench a la carpeta de Aplicaciones.

Si teneís cualquier problema con la instalación recordad que lo haremos de nuevo en clase, así que no os preocupéis.Y podéis escribirme un correo si tenéis cualquier duda.
