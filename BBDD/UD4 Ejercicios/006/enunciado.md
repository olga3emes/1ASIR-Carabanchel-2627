Ejercicio: Centro de Investigación Pokémon

Hasta el momento se registran los siguientes datos en diversos documentos:

Para cada entrenador:

Número de entrenador (único).
Nombre.
Dinero disponible.
Varias regiones visitadas.

Para cada Pokémon:

Número de Pokédex (único).
Nombre.
Tipo principal.
Nivel actual.

Para cada combate:

Código de combate (único).
Fecha.
Lugar donde se realiza.

Para registrar un combate se necesita:

El entrenador que participa.
Los Pokémon que utiliza durante el combate.
Para cada Pokémon participante deberá almacenarse el daño realizado.

Además, se desea almacenar información sobre los gimnasios:

Código de gimnasio (único).
Nombre.
Ciudad.

Un gimnasio puede especializarse en varios tipos Pokémon y un tipo Pokémon puede estar presente en varios gimnasios.

Se desea registrar qué Pokémon pueden evolucionar a otros Pokémon. Para cada evolución se almacenará el nivel mínimo requerido para evolucionar.

También interesa conocer cuántos Pokémon posee cada entrenador, aunque este dato no debe almacenarse explícitamente.

Se pide
Identificar las entidades.
Identificar los atributos de cada entidad.
Identificar las relaciones y sus cardinalidades.
Determinar qué atributos son derivados.
Dibujar el diagrama E-R utilizando la notación de Chen.
